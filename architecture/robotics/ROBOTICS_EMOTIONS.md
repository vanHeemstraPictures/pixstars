# ROBOTICS_EMOTIONS.md

Version: 1.0

⸻

Purpose

Emotion is the primary mechanism through which the audience perceives life.

Without emotion:

Robot

With emotion:

Character

⸻

Emotion Model

PixStars emotions are represented as weighted values.

Example:
```
{
  "curiosity": 0.8,
  "joy": 0.6,
  "confusion": 0.2,
  "sadness": 0.0
}
```
⸻

Core Emotions

Curiosity

Visual Indicators:

* Head tilt
* Forward lean

Voice:

* Questioning
* Exploratory

⸻

Joy

Visual Indicators:

* Upward posture
* Brighter light

Voice:

* Faster cadence
* Positive tone

⸻

Pride

Visual Indicators:

* Taller posture
* Deliberate movement

Voice:

* Confident

⸻

Confusion

Visual Indicators:

* Repeated tilts
* Small corrections

Voice:

* Hesitation

⸻

Sadness

Visual Indicators:

* Lower posture
* Dimmer light

Voice:

* Slower speech

⸻

Remorse

Important for the Walt/A.I. storyline.

Visual Indicators:

* Motion freeze
* Reduced brightness

Voice:

* Quiet
* Reflective

⸻

Emotion Sources

* Story events
* Audience interaction
* Voice conversations
* Memory recall
* Performance cues
