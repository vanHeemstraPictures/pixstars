# CHARACTER_ANIMATION_PRINCIPLES.md

Version: 1.0

Purpose

PixStars should borrow principles from character animation.

The audience should perceive life through motion.

⸻

Principle 1 — Intent Before Motion

Never move randomly.

Every movement answers:

Why?

⸻

Principle 2 — Anticipation

Before motion:

Prepare.

Example:
```
Pause
↓
Look
↓
Move
```
⸻

Principle 3 — Follow Through

Motion should not stop instantly.

Example:
```
Lamp swings.

↓

Settles.

↓

Stops.
```
---
# Principle 4 — Timing
```
Fast:
- Surprise
- Excitement
```

```
Slow:
- Thoughtfulness
- Sadness
```
---
# Principle 5 — Focus
The audience must know:
```text
What is the lamp paying attention to?
```
⸻

Principle 6 — Curiosity

Default state.

When idle:

* Observe
* Scan
* Listen

⸻

Principle 7 — Stillness

Stillness is powerful.

A completely still lamp can communicate:

* Shock
* Fear
* Sadness
* Reflection

⸻

Principle 8 — Character First

Ask:

What would the character do?

before asking:

What can the technology do?

⸻
